# Keygen Metadata Generator

A simple console application to help generate metadata JSON for Keygen licenses.

## Purpose

This tool collects license details from the user and generates properly formatted JSON that can be used as metadata in Keygen licenses.

## Usage

### Build and Run

```bash
cd tools/KeygenMetadataGenerator
dotnet run
```

Or build and run the executable:

```bash
dotnet build
cd bin/Debug/net8.0
./KeygenMetadataGenerator.exe
```

### Interactive Prompts

The tool will prompt you for:

1. **Domain** - Domain restriction (e.g., `*.brucepower.com`)
2. **Fingerprint** - Machine fingerprint (SHA-256 hex string)
3. **Modules** - Either `all` or a list like `mod_aes67/mod_opus/mod_conference`
4. **Max Machines** - Maximum number of machines (optional)
5. **Expiry Date** - License expiration date in YYYY-MM-DD format (optional)
6. **Custom Fields** - Any additional metadata fields you need

### Domain OR Fingerprint Logic

When both `domain` and `fingerprint` are specified, the license validation uses **OR logic**:
- License is **valid** if the machine's domain matches **OR** the machine's fingerprint matches
- License is **invalid** only if **both** fail to match

This provides flexibility for different deployment scenarios.

### Example Output

```json
{
  "domain": "*.brucepower.com",
  "modules": "all"
}
```

Compact format for copy/paste:
```json
{"domain":"*.brucepower.com","modules":"all"}
```

## How to Use with Keygen

### For Online Licenses (with API access):

1. Run this tool and copy the generated JSON
2. Go to Keygen dashboard → Create/Edit License
3. Add metadata fields individually:
   - **Key**: `domain`, **Value**: `*.brucepower.com`
   - **Key**: `modules`, **Value**: `all`
4. Save the license
5. The metadata will be available when validating the license via the API

### For Offline Licenses:

⚠️ **Important**: Keygen signed licenses do NOT include custom metadata in the cryptographic payload.

For offline licenses with domain/module restrictions, you have two options:

1. **Use a separate metadata file**:
   - `license.lic` (Keygen signed license)
   - `license.meta` (JSON file generated by this tool)

2. **Require initial online validation**:
   - First validation happens online and caches metadata
   - Subsequent validations can work offline with cached metadata

## Fields

### Standard Fields

- **domain** - Domain restriction (supports wildcards like `*.example.com`)
- **fingerprint** - Machine fingerprint restriction (SHA-256 hex string, 64 characters)
- **modules** - Licensed modules (`all` or comma/slash-separated list)
- **maxMachines** - Maximum machines (integer)
- **expiry** - Expiration date (ISO 8601 format)

### Custom Fields

You can add any additional custom fields needed for your licensing logic.

## Notes

- Empty fields are omitted from the output JSON
- The tool generates both pretty-printed and compact JSON formats
- Dates are formatted in ISO 8601 format for consistency
- For domain wildcards, use `*.` prefix (e.g., `*.brucepower.com`)
